An educational compliance simulation that analyzes fictional outpatient medical records and flags potential billing, coding, and documentation discrepancies for certified human auditor review.

> ### ⚠️ Mandatory Compliance & Educational Notice
> - **Educational Simulation Only:** This software is built strictly for educational training, academic demonstration, and compliance workflow learning.
> - **Historical Reference Version Disclosure:** The audit rules and reference lookups utilize historical reference datasets: **FY 2024 ICD-10-CM** and **CPT 2024 (Educational Reference Subset)**. These datasets are historical educational subsets and do NOT reflect current FY 2026 / FY 2027 code-set revisions. This tool does not claim current regulatory compliance.
> - **Not Certified Advice:** The findings and recommendations generated by this tool **do not** constitute certified medical coding advice, legal counsel, or official billing instructions.
> - **Non-HIPAA Certified:** This system is designed solely for synthetic, de-identified fictional patient records. Never load real Protected Health Information (PHI).
> - **Human Review Required:** Automated audit flags highlight potential discrepancies requiring investigation by certified coding professionals (CPC, CCS, CPMA).
> - **Zero Automatic Alterations:** Under compliance governance rules, this software **never automatically modifies** a patient's clinical chart or billed codes.

## 🌟 Key Features

1. **Medical Record Management**
   - Ingests fictional patient encounters containing Encounter IDs, Patient IDs, age, gender, encounter dates, clinical documentation, documented diagnoses, assigned ICD-10-CM codes, procedure descriptions, assigned CPT codes, and documentation completeness status.
   - Includes 20 pre-packaged synthetic training encounters illustrating clean visits, code mismatches, documentation omissions, duplicate coding, unverified codes, and medical necessity gaps.
   - Supports uploading custom CSV files.

2. **Compliance Audit Engine**
   - **Missing Clinical Documentation:** Identifies encounters where notes are completely empty while codes are billed (*Medicare Program Integrity Manual Pub. 100-08*).
   - **Missing Diagnosis Documentation:** Identifies assigned ICD-10-CM codes lacking clinical documentation support (*ICD-10-CM Guideline I.B.1*).
   - **Diagnosis-to-Code Mismatch:** Flags conflicts between documented conditions and assigned codes (e.g., Essential Hypertension documented but Diabetes code assigned).
   - **Unverified Reference Codes:** Flags codes outside active reference subsets for manual tabular verification.
   - **Documentation Completeness & Length:** Flags notes under word count thresholds (<15 words).
   - **Clinician Signature Authentication:** Verifies provider electronic signature and credentials (*CMS MLN Matters MM6698*).
   - **Duplicate Coding Detection:** Detects duplicate diagnosis or procedure codes billed on the same encounter date (*CMS Pub. 100-04* & *NCCI Manual*).
   - **Unsupported Procedure Coding:** Flags CPT codes lacking dedicated procedure reports or medical necessity justification (*Social Security Act §1862(a)(1)(A)*).
   - **High-Level E/M Substantiation:** Guards against unsupported Level 5 E/M codes (*CPT 99215 / 99205*).
   - **Specificity Optimization:** Identifies unspecified codes used when clinical notes document specific laterality or manifestations.

3. **Version-Aware Validation Standards**
   - Maintains rule definitions and code sets in separate JSON data files (`data/rules/`).
   - Uses standardized FY 2024 ICD-10-CM and 2024 CPT educational reference subsets with explicit `code_set_year` metadata.
   - Features real, un-fabricated regulatory citations (CMS Claims Processing Manual, Program Integrity Manual, ICD-10 Official Guidelines, AMA CPT instructions).

4. **Interactive Streamlit Dashboard**
   - KPI metrics: Total Records Audited, Requires Manual Review, Correctly Documented, Potential Coding Errors, Documentation Deficiencies.
   - Publication-grade Matplotlib charts: Severity Breakdown donut, Issues by Category horizontal bar, and Clean vs Flagged status chart.
   - Filterable findings table with multi-select severity and issue filters and search capability.
   - Detailed Record Explorer with side-by-side view of clinical documentation vs audit rationale.

5. **Multi-Format Export Hub & 14-Section Word Audit Report**
   - Export audit findings table directly as CSV (`reports/medical_coding_compliance_findings.csv`).
   - Generate a formatted Microsoft Word audit report (`reports/Medical_Coding_Compliance_Audit_Report.docx`) adhering to the 14-section compliance standard:
     1. Cover page
     2. Executive summary
     3. Introduction
     4. Objectives
     5. Scope and limitations
     6. Audit methodology
     7. Coding compliance criteria
     8. Dataset description
     9. Detailed audit findings with encounter IDs
     10. Issue-wise explanations
     11. Corrective actions
     12. Preventive recommendations
     13. Conclusion
     14. References

6. **Comprehensive Unit Test Suite**
   - 17 unit tests covering CSV loading, missing fields, duplicate coding, unverified codes, negation detection, exact/concept diagnosis matching, audit findings generation, 14-section Word report generation, and individual rule checks.

## 🚀 Quick Start Guide

### 1. Prerequisites
- Python 3.10 or higher
- `pip` package manager

### 2. Installation
Navigate to the project root directory:
```bash
pip install -r requirements.txt
```

### 3. Run Unit Tests
Verify all 17 compliance rule tests pass:
```bash
pytest -v
```

### 4. Launch the Streamlit Dashboard
Start the interactive compliance application:
```bash
streamlit run app.py
```
Open your browser to `http://localhost:8501`.

### 5. Generate Word Report & Findings CSV via CLI
Generate the standalone Word compliance audit report and CSV findings independently of the dashboard:
```bash
python generate_reports.py
```
Or specify custom paths:
```bash
python generate_reports.py --input data/sample_records.csv --output-dir reports
```
